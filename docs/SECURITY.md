# SEGURANÇA

A API deve escutar em localhost por padrão.

Acesso LAN exige ativação explícita.

Implementar:

- Autenticação.
- Autorização.
- Controle de origem.
- Proteção de WebSocket.
- Limitação de requisições.
- Validação de entradas.
- Proteção de credenciais.
- Separação de permissões.
- Confirmação de operações destrutivas.

Não registrar tokens e senhas.

Plugins não confiáveis devem ser isolados quando possível.

Telemetria externa desativada por padrão.

Não executar scripts remotos sem autorização e controle de segurança.
